Microsoft Outlook [webhooks](https://learn.microsoft.com/en-us/graph/api/resources/change-notifications-api-overview?view=graph-rest-1.0) (also called change notifications or subscriptions) send notifications to the flow's webhook URL when Outlook resources change.

#### How It Works

Microsoft Graph sends a validation request when the subscription is first configured. This validation is routed to the **URL Validation** branch. The trigger automatically responds with the validation token to complete setup. All subsequent event notifications are routed to the **Notification** branch.

To configure a webhook subscription, use the accompanying [Subscription](https://learn.microsoft.com/en-us/graph/api/subscription-post-subscriptions?view=graph-rest-1.0) actions provided in the component.

**Supported resources**: Calendar events (`me/events`), mail messages (`me/messages`), mail folders (`me/mailFolders`), contacts (`me/contacts`)
