The New and Updated Campaigns trigger checks for new and updated campaigns in a Google Ads account on a configured schedule. It monitors campaign properties including status, budget, bidding strategy, and settings by comparing the current state against the previous polling state.

This trigger uses the [Google Ads API Campaign resource](https://developers.google.com/google-ads/api/fields/v25/campaign) to query campaign data and performs client-side change detection between polling intervals.

#### How It Works

1. Run on the configured schedule (e.g., every 15 minutes)
2. Query campaigns modified since the last poll using [Google Ads Query Language](https://developers.google.com/google-ads/api/docs/query/overview)
3. Compare current campaign data against stored state to identify changes
4. Categorize changes as "created", "updated", or "deleted"
5. Update state with current campaign data for the next poll

**Batching**

This trigger supports opt-in batching. When batching is enabled on the flow, each campaign change (or each group of up to the configured batch size) is dispatched as its own execution rather than delivering all changes in a single payload. The default batch size is 50.

Batching splits the executions, not the fetch: the trigger still retrieves the full set of changed campaigns in a single poll before any dispatching happens. When batching is enabled, each execution receives one item:

```json
{
  "changeType": "budget",
  "record": {
    "changeType": "budget",
    "campaignId": "12345678901",
    "campaignName": "Example-Campaign-1",
    "field": "budget_amount_micros",
    "oldValue": "50000000",
    "newValue": "75000000",
    "changedAt": "2026-01-01 12:05:00"
  }
}
```

#### Returned Data

The trigger returns an object containing detected changes and metadata. When no changes are detected, returns `polledNoChanges: true`.
