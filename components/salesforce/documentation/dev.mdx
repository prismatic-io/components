This component includes CRUD (create, read, update, delete) actions for records and a create action for leads.
For more complex queries, the [Salesforce Object Query Language](https://developer.salesforce.com/docs/atlas.en-us.soql_sosl.meta/soql_sosl/sforce_api_calls_soql.htm) and the query action of this component are available.

#### Listening for events in Salesforce

Salesforce can send notifications when a record is created, updated, deleted, or undeleted.
To listen for these events, use the [Outbound Messaging](https://developer.salesforce.com/docs/atlas.en-us.api.meta/api/sforce_api_om_outboundmessaging_understanding.htm) feature of Salesforce.

When a Salesforce Flow is created, the conditions that cause the rule to run are specified.
When those conditions are met, Salesforce sends an outbound message to the URL specified in the outbound message.

The **Flow Outbound Message Webhook** trigger can be used to run on instance deploy and will configure the necessary Flows and outbound messages automatically.
