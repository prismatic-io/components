:::warning[Salesforce Workflow Rules Retired December 31, 2025]
Salesforce [ended support](https://help.salesforce.com/s/articleView?language=en_US&id=001096524&type=1) for Workflow Rules and Process Builder on **December 31, 2025**, so webhook subscriptions that rely on them are no longer supported and should be migrated to the [Flow Builder](https://help.salesforce.com/s/articleView?language=en_US&id=platform.flow.htm&type=5). To migrate, configure existing integrations to use the **Flow Outbound Message Webhook** trigger, which on deploy creates a new active Flow and Outbound Message and removes the original Outbound Message, leaving the Workflow Rule intact but inactive. The new trigger returns a different payload, so review and update any steps that reference the trigger payload.
:::

Outbound Message functionality is unaffected, and Flows are compatible with Outbound Messages. For an overview of the Flow trigger functionality, see the [Flow Outbound Message Webhook demonstration](https://vimeo.com/1118182531/9a2f82bf2e?share=copy).
