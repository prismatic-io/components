A common integration pattern involves listing files in a file store, and performing a series of actions on the array of files that are returned.
See our [looping over files](integrations/common-patterns/loop-over-files.mdx) quickstart for information about how to create a loop over an array of files.

### Streaming large files to S3

Amazon S3 offers a feature called [multipart upload](https://docs.aws.amazon.com/AmazonS3/latest/userguide/mpuoverview.html) that allows uploading large files in parts.
This component supports multipart uploads in two ways:

1. **File Streaming**: This is useful when looping over a paginated API and streaming the response to S3 as a CSV (or similar) file.
   This option is useful when there is a large number of records to process and loading all of them into memory at once should be avoided (which can cause an out-of-memory error).
   When the **Upload Stream** actions are used, the component automatically handles the multipart upload.
   Within the integration:

   - Run a **Create Upload Stream** action to create a new file stream.
   - Loop over the records to write to the file.
     - For each record, run a **Write Upload Stream** action to write the record to the file stream.
   - Run a **Close Upload Stream** action to close the file stream and upload the file to S3.

2. **Multipart Upload**: This is useful if a file is already split into parts that need to be uploaded to S3 and then joined together.
   Within the integration:

   - Run a **Create Multipart Upload** action to start a new multipart upload.
   - Run a **Generate Presigned URL for Multipart Uploads** action to generate a presigned URL for each part.
   - Run an HTTP component **Post** action to post each part to the presigned URL.
   - Run a **Complete Multipart Upload** to complete the multipart upload.

   This option requires manually handling the multipart upload process and abiding by the restrictions that Amazon S3 imposes on multipart uploads (like each part being at least 5MB in size, with the exception of the last part).
